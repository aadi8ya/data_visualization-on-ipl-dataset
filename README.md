# IPL Data Analysis & Visualization 🏏

This project performs exploratory data analysis (EDA) and visualization on the IPL dataset using Python, Pandas, Matplotlib, and Seaborn.

## 📌 Features & Insights
- **Match Winners**: Visualization of total match wins by each team.
- **Toss Analysis**: Analysis of toss decisions (Bat vs Field) and toss winner vs match winner correlation.
- **Match Results**: Breakdown of win margins (by Runs vs Wickets).
- **Player Stats**: 
  - Top 10 Player of the Match award winners.
  - Highest individual run scorers.
  - Top bowling performances and best figures.
- **Venue Insights**: Venues with the maximum number of matches played.

## 🛠️ Tech Stack & Libraries
- **Language**: Python
- **Data Manipulation**: Pandas, NumPy
- **Data Visualization**: Matplotlib, Seaborn
- **Environment**: Google Colab / Jupyter Notebook
